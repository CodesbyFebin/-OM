# Contributing to OM — Personal AI Operating Universe

Thank you for your interest in contributing to **om-personal-ai-universe**!

## 🚀 Principles

1. **Sovereignty First**: All code must respect user privacy, local-first data ownership, and strict zero-knowledge boundaries.
2. **Explicit Provenance**: Every AI decision, sub-agent action, and background job must carry explicit status and provenance headers.
3. **No Hidden Endpoints**: All external or local services must go through server-side bridges with SSRF protection and circuit breaking.

## 🛠️ Development Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/om-personal-ai-universe.git
   cd om-personal-ai-universe
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run local dev server:
   ```bash
   npm run dev
   ```

4. Verify types and linting:
   ```bash
   npm run lint
   ```

## 📋 Pull Request Process

1. Fork the repo and create your feature branch (`git checkout -b feature/amazing-feature`).
2. Ensure code compiles cleanly (`npm run lint` and `npm run build`).
3. Commit your changes with clear, descriptive messages (`git commit -m 'Add new agent pipeline'`).
4. Push to your branch and open a Pull Request.
