## Deployment Instructions

Extract and push Phase 4 repositories:

```bash
cd /home/user
for bundle in awesome-ai-*.tar.gz ai-*.tar.gz compliance-*.tar.gz; do
  repo="${bundle%.tar.gz}"
  tar -xzf "$bundle"
  cd "$repo"
  git remote add origin "https://github.com/CodesbyFebin/$repo.git"
  git push -u origin main
  cd ..
done
```

All Phase 4 .tar.gz bundles located in `/home/user/`
